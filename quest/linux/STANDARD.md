# 標準入出力を扱える

## 1. 標準入出力とは

標準入力、標準出力、標準エラー出力について、プログラミング初心者にわかるように説明してください。

プログラムは,データを受け取り,処理し結果を出すという流れで動く．Linuxでは，この「入り口」と「出口」があらかじめ決まっており，これを標準入出力と呼ぶ．
標準入力：0　キーボードからの入力．プログラムにデータを渡す入口．
　　　　　　 人間でいう耳
標準出力：1　画面表示．正常に処理された結果が出てくる出口
標準エラー出力：2　エラーメッセージが出てくる出口
出力は口から出すイメージ

## 2. リダイレクト

リダイレクトを使用して、ルートディレクトリを ls コマンドで出力した結果を、~/root.txt という新規ファイルに保存してください。
```bash
# コードを実行
ls / > ~/root.txt
# ファイルの中身を表示
cat root.txt　
```

## 3. エラー出力のリダイレクト

コマンドを実行してエラーになった際に、エラー結果を ~/error.txt という新規ファイルに保存してください。エラーを発生させるにはは例えば ls /hoge など、存在しないファイル・ディレクトリを ls コマンドで参照する方法があります。
```bash
# コードを実行
ls hoge 2> ~/error.txt
cat error.txt
```

## 4. 出力とエラー出力のリダイレクト

ルートディレクトリと存在しないファイルを ls コマンドで一度で参照しようとして( ls / /hoge )、その両方の結果を一度に ~/result.txt という新規ファイルに保存してください。
```bash
# コードを実行
# &を使う
ls / /hoge &> ~/result.txt
```

## 5. /dev/null とは

/dev/null とは何で、どういう時に使われるものかをプログラミング初心者にわかるように説明してください。

Linuxのシステムにおけるゴミ箱のようなもの．データを入れても保存されない．

## 6. /dev/null へのリダイレクト

ルートディレクトリを ls コマンドで参照した結果を、/dev/null にリダイレクトし、何も表示されないことを確認してください。
```bash
# コードを実行
ls / > /dev/null
```

## 7. パイプライン：パイプライン "|" は，左側のコマンドの出力結果  を　　　             そのまま右側のコマンドの入力として渡す機能．

ルートディレクトリを ls コマンドで参照した結果のうち、"l" から始まるものだけを、パイプラインを使用して一回のコマンドで表示してください。
```bash
# コードを実行
ls / | grep "^l"

# 実行結果
lib
lib.usr-is-merged
lib64
lost+found
```
